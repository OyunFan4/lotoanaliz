# LotoAnaliz AI — otomatik veri altyapısı / kontrollü geliştirme

> Mevcut mobil arayüz, PWA, geçmiş cihaz kayıtları ve sekmeler korunmuştur. `sync` yanıtının biçimi eski UI ile uyumludur. Otomatik veri toplama kaynak doğrulanmadan **tamamlandı** olarak beyan edilmez.

## Gerçek durum (26.10.2026)

- **İki oyunun CollectAPI adaptörü:** Çılgın Sayısal Loto ve Süper Loto. Son kullanıcı testlerinde iki uç nokta da HTTP 500 dönmüştü. Bugün canlı yanıt doğrulanmadı; otomatik aktarım garantisi yok.
- **Şans Topu ve On Numara:** Kural/doğrulama altyapıları hazır; resmî veya izinli çalışan API adresleri doğrulanmadı, bağlanmadılar.
- **Resmî doğrulama:** CollectAPI üçüncü taraf kaynağıdır. Bu kaynaktan çekilen hiçbir veriyi `official_verified` diye işaretlemeyin.
- **Geçmiş çekilişler:** İzinli sayfalama/tarih aralığına sahip çalışan veri kaynağı henüz bulunmadığı için otomatik geriye dönük tam aktarım yapılmamıştır.
- **İşlem:** Netlify'daki zamanlanmış kontrol her dört saatte bir (UTC, saat başından 15 dakika sonra) dört oyun için çalışır. İki oyunda veri kaynağını dener; diğer iki oyun için `not_configured` kaydı tutar. Aynı çekilişi yeniden eklemez.
- **Güvenlik:** Public sync endpointi sadece sorgulama yapar, kalıcı DB'ye yazmaz; kalıcı kayıt yalnızca arka plan zamanlayıcısından yapılır. Gizli anahtarlar sadece Netlify Functions ortamında tutulur.

## Kurulum

1. Mevcut `lotoanaliz` deposunun bir yedeğini alın ve bu ZIP'in içeriklerini ana dizine ekleyin. `index.html`, `app.js`, `style.css` ana dizinde, `netlify/functions/` aynı konumda olmalıdır. GitHub'a **asla gerçek .env veya API anahtarı** yüklemeyin.
2. https://supabase.com adresinde bir proje oluşturun. Supabase SQL Editor'da `supabase/001_initial.sql` çalıştırın.
3. Netlify → Project configuration → Environment variables:
   - `SUPABASE_URL`: Supabase proje URL'si
   - `SUPABASE_SERVICE_ROLE_KEY`: Supabase **secret** service_role key (GitHub'a ve tarayıcıya koymayın)
   - `COLLECTAPI_KEY`: CollectAPI'de **yenilediğiniz** anahtar (geçmişte sohbet içinde paylaşılmış anahtar kullanılmamalı). Başına `apikey ` eklemeyin.
4. Netlify'da yeniden deploy edin. Production deploy tamamlanınca `/.netlify/functions/health` ve `/.netlify/functions/summary` adreslerini deneyin.
5. `/.netlify/functions/sync?game=sayisal` ve `?game=super` arayüzle uyumluluğu gösterir; bunlar tarayıcıdan tetiklenen *okuma* kontrolleridir. Kalıcı veritabanını zamanlanmış görev yazar.
6. `/.netlify/functions/history?game=sayisal` arşivi, `/.netlify/functions/summary` son 20 kontrol günlüğünü gösterir.
7. Netlify Function loglarında `Scheduled LotoAnaliz check` mesajını arayın. **Netlify'da çalışmadığını görmediğiniz bir işi tamamlandı diye kabul etmeyin.**

## Yedekleme ve geri yükleme

Supabase'de SQL Export veya PostgreSQL `pg_dump` kullanarak düzenli yedek alın. Geri yükleme öncesinde test ortamında `pg_restore` ile kurtarma doğrulaması yapın. Mevcut cihaz kayıtları ayrı bir yerel tarayıcı depolamasındadır; bu paket onları kendiliğinden silmez veya server'a taşımış gibi davranmaz.

## Bilinen sınırlamalar ve sonraki adım

- Kaynak CollectAPI 500 vermeye devam ederse yeni veri gelmeyecektir; geçmiş veriler **korunur**.
- Kamuya açık API için ilk seviye CDN 5 dakikalık önbellek vardır; yoğun trafik için Netlify rate limit/WAF gibi ek kontrol gerekir.
- Resmî/izinli veri erişimi, çekiliş numarası ve tarih eşleştirmesi, dört oyunun tüm arşivi, kaynak çelişkilerinin ayrı tabloya alınması ve uçtan uca üretim testleri **henüz tamamlanmadı**.
- `archive/history` ilk 500 kayıtla sınırlıdır; tam tarihi aktarım ve sayfalama ileride gerçek veri kaynağına bağlanarak geliştirilmeli.
- PWA cihaz üzerindeki verileri kaldırmak için **tarayıcı verilerini temizlemeyin**.
- Terminal testi: `node --test tests/core.test.mjs`. Bu testlerde gerçek çekiliş sonucu uydurulmaz.

# LotoAnaliz AI V9 — Netlify + telefon testi

1. Dosyaları GitHub deposunun **kök dizinine** yükleyin (`index.html` ve `netlify.toml` kökte kalmalı). `netlify/functions/` klasörünü koruyun. GitHub deposu Netlify projenize bağlı olmalı.
2. Netlify Deploys ekranında son dağıtımın **Published** olduğuna bakın.
3. `https://lotoanaliz.netlify.app/api/health` adresini açın. JSON içinde `ok: true` beklenir. 404 veya HTML hata sayfası görürseniz Netlify Function yayımlanmamıştır.
4. `https://lotoanaliz.netlify.app/api/sync?game=super` adresini açın. `results` dolu ve `status: ok` ise veri alınmıştır. `status: unavailable` ise kaynak doğrulanamamış demektir; `errors` nedenini açıklar.
5. Telefonda sitenin son sürümünü açın, yenileyin. Eski PWA görünüyorsa Android'de tarayıcı sitesini yeniden yükleyin. **Cihaz verilerini silmeyin**; önce Diğer → JSON yedeğini indir.
6. **Özet**, **Arşiv** veya **Diğer** bölümünde **Şimdi sonuçları kontrol et** butonuna dokunun. İki oyunun ayrı ayrı durumunu görün.
7. Alınamayan çekiliş için Arşiv → Bir çekilişi elle ekle formunu doldurun. Manuel kayıtlar silinmez.

## Sınırlamalar

Resmî sonuç sayfaları sunucu isteğinde işlenmemiş şablon gönderebilir veya 403/429 döndürebilir; bunlar engellenmez ve sahte sonuç üretilmez. Fonksiyon yalnızca sınırlı güncel çekiliş adaylarını sorgular, bütün geçmişi taramaz. Netlify tarayıcı sürümündeki kayıtlar IndexedDB içinde yalnızca bu cihazda saklanır. Manuel kayıtlar resmî doğrulanmış sayılmaz. Bu paketin canlı Netlify dağıtımı ve sonuç çekme başarısı bu ortamda doğrulanmamıştır.

MAXIMUM = {'sayisal': 90, 'super': 60}

def validate(game, numbers):
    if game not in MAXIMUM: raise ValueError('Geçersiz oyun')
    if len(numbers)!=6 or any(type(x) is not int or not 1<=x<=MAXIMUM[game] for x in numbers) or len(set(numbers))!=6:
        raise ValueError('Altı farklı ve kurala uygun tam sayı gerekli')

def frequency(game, draws):

    last={n:None for n in range(1,m+1)}; gaps={n:total for n in range(1,m+1)}
    for i,d in enumerate(draws):
        for n in d['numbers']:last[n]=d['date'];gaps[n]=total-1-i
    return [{'number':n,'hits':hits[n],'rate':hits[n]/total if total else 0,
             'expected_rate':6/m,'last_seen':last[n],'draws_since':gaps[n],
             **{f'last_{period}':sum(n in d['numbers'] for d in draws[-period:]) for period in (10,25,50,100,250)}} for n in range(1,m+1)]

def distribution(game, draws, low_boundary=None):
    mid=low_boundary or MAXIMUM[game]//2
    odds=Counter(); lows=Counter(); sums=Counter(); consecutive=0
    for d in draws:
        a=d['numbers'];odds[sum(n%2 for n in a)]+=1;lows[sum(n<=mid for n in a)]+=1
        sums[sum(a)]+=1;consecutive+=int(any(b-a==1 for a,b in zip(a,a[1:])))
    return {'sample_size':len(draws),'low_boundary':mid,'odd_counts':dict(odds), 'low_counts':dict(lows),

def cooccurrence(draws, size=2, limit=30):
    if size not in (2,3):raise ValueError('Yalnızca ikili ve üçlü')
    c=Counter(combo for d in draws for combo in combinations(d['numbers'],size))
    return [{'numbers':list(k),'hits':v} for k,v in sorted(c.items(), key=lambda x:(-x[1],x[0]))[:limit]]

def generated(game, strategy, training, rng):
    m=MAXIMUM[game]; weights=[1]*m
    if strategy in ('hot','recent','hybrid','pairs'):
        used=training[-25:] if strategy=='recent' else training
        for d in used:

def backtest(game, draws, strategy='random', count=1, warmup=25, seed=42):

def connect_db():
    db=sqlite3.connect(DB_PATH, timeout=10)
    db.row_factory=sqlite3.Row
    db.execute('PRAGMA busy_timeout=10000')
    db.execute('CREATE TABLE IF NOT EXISTS results (game TEXT NOT NULL,year INTEGER NOT NULL,draw_number INTEGER NOT NULL,draw_date TEXT NOT NULL,numbers TEXT NOT NULL,source_url TEXT NOT NULL,fetched_at TEXT NOT NULL,PRIMARY KEY(game,year,draw_number))')
    db.execute('CREATE TABLE IF NOT EXISTS checks (game TEXT PRIMARY KEY,checked_at REAL NOT NULL,status TEXT NOT NULL,message TEXT NOT NULL)')
    db.execute('CREATE TABLE IF NOT EXISTS sync_jobs (id INTEGER PRIMARY KEY AUTOINCREMENT, game TEXT NOT NULL, year INTEGER, started_at TEXT NOT NULL, finished_at TEXT, checked INTEGER DEFAULT 0, inserted INTEGER DEFAULT 0, rejected INTEGER DEFAULT 0, status TEXT NOT NULL, cursor INTEGER DEFAULT 1, message TEXT DEFAULT "")')

1. Bilgisayar/sunucuda Python 3.10+ kurulu olsun.
2. Bu klasörde: pip install -r requirements.txt
3. Ardından: uvicorn server:app --host 0.0.0.0 --port 8000
4. http://localhost:8000 sayfasını açın.
5. Android PWA kurulumu için HTTPS alan adıyla yayımlayın.

HER AÇILIŞTA:
- Tarayıcı sunucunun /api/sync hizmetini kontrol eder.
- Sunucu sonuç sayfalarını kısıtlı sayıda ve kontrollü inceler.
- Erişilebilen ve biçimi doğrulanabilen kayıtlar saklanır.

- Sonuç alınamazsa uygulama çevrimdışı kayıtlarla kullanılmaya devam eder.

SINIRLAMALAR:
- Sonuç sitesine erişim engeli/CAPTCHA aşılmaz.
- Tüm tarihsel verileri eksiksiz alma sistemi değildir.
- Kaynak site HTML yapısı değişirse doğrulama başarısız olabilir.
- Varsayılan sunucu sınırlı sayıda güncel çekilişi inceler.
- SQLite veritabanı sunucuda saklanır. Üretimde kalıcı disk kullanın.

- Resmî siteye erişim bu ortamda ağ DNS kısıtı nedeniyle canlı test edilemedi.

# Son sürüm kontrol ve sınırlamalar

- **Canlı resmî site çekimi doğrulanmadı.** Resmî sayfalara buradaki Python ortamından doğrudan ağ erişimi yok. Gerçek HTTPS sunucuda uçtan uca deneme yapılmalı.
- **Geçmiş arşiv tamlığı doğrulanmadı.** Yönetici kontrollü tarama partiler hâlindedir; 403 / 429 engelleri aşılmaz. Resmî kaynağın kullanım koşullarına uyun.
- **Veritabanı SQLite.** Kalıcı disk ile tek sunuculu kullanım içindir; PostgreSQL migration bu pakette yoktur.
- **Mobil Android / iOS gerçek cihaz testleri yapılmadı.** Ana ekran kurulumu HTTPS gerektirir.
- **Bildirimler / hesaplar arası senkronizasyon** mevcut değil. Veri cihaz üzerinde saklanır; yedek kullanın.
- **CSV API yüklemeleri asla resmî doğrulanmış sayılmaz.** Yönetici anahtarı gerektirir.
- **Gelecek tarihler / eski oyun kuralı değişimleri** tam tarihsel modelle yönetilmedi; ilk tarihsel dönemleri aktarmadan kontrol edin.
- **Kazanma garantisi yoktur.** İstatistik ve geriye dönük sonuçlar adil çekilişte bir kombinasyonun çekilme olasılığını artırmaz.

def parse_result(html,game,year,number,url):
    soup=BeautifulSoup(html,'html.parser')
    if '{{#each' in html or '{{this}}' in html:
        raise ValueError('Resmî HTML sonuç sayıları yerine işlenmemiş şablon içeriyor')
    # Require an actual results heading and explicit draw number to avoid parsing adverts.
    heading=next((h.get_text(' ',strip=True) for h in soup.find_all(['h1','h2']) if 'Sonuçları' in h.get_text(' ',strip=True) and ('Süper Loto' if game=='super' else 'Sayısal Loto') in h.get_text(' ',strip=True)),None)
    if not heading: raise ValueError('Beklenen çekiliş başlığı yok')
    pat=re.search(r'(\d{1,2})\s+([A-Za-zÇĞİÖŞÜçğıöşü]+)\s+(\d{4})',heading)
    if not pat: raise ValueError('Başlıktan tarih okunamadı')
    mon=MONTHS.get(pat.group(2).casefold())
    if not mon: raise ValueError('Bilinmeyen ay')
    when=date(int(pat.group(3)),mon,int(pat.group(1)))
    if when.year!=year or when>date.today(): raise ValueError('Çekiliş tarihi uyuşmuyor')
    text=soup.get_text('\n',strip=True)
    no=re.search(r'Çekiliş\s*no\s*:\s*(\d+)',text,re.I)
    if not no or int(no.group(1))!=number: raise ValueError('Çekiliş numarası uyuşmuyor')
    label=next((tag for tag in soup.find_all(['h2','h3','h4']) if 'Kazanan Numaralar' in tag.get_text(' ',strip=True)),None)
    if label:
        chunks=[]
        for node in label.next_elements:
            if getattr(node,'name',None) in ('h1','h2','h3','h4') and node is not label:break
            if isinstance(node,str):
                s=node.strip()
                if s:chunks.append(s)
            if len(chunks)>70:break
        number_text=' '.join(chunks)
    else:
        split=re.split(r'Kazanan Numaralar',text,maxsplit=1)
        number_text=split[1].split('Kazanan Kategoriler')[0] if len(split)>1 else ''
    number_text=number_text.split('Kazanan Kategoriler')[0]
    # Only isolated number elements count.  Additional Joker/SuperStar numbers are excluded.
    pieces=re.findall(r'(?<!\d)\b\d{1,2}\b(?!\d)',number_text)
    expected=8 if game=='sayisal' else 6
    if len(pieces)!=expected: raise ValueError(f'Ana ve ek sayılar kesin olarak ayrılamadı ({len(pieces)} aday; beklenen {expected})')
    nums=sorted(map(int,pieces[:6]))
    if any(x<1 or x>GAMES[game][1] for x in nums) or len(set(nums))!=6:raise ValueError('Sayılar oyun kuralına uymuyor')
    return {'game':game,'date':when.isoformat(),'drawNumber':str(number),'numbers':nums,'status':'official_verified','sourceUrl':url,'fetchedAt':datetime.now(timezone.utc).isoformat()}

def expected_latest(game,now):
    # Approximate draw number only for choosing probe candidates; never interpret missing numbers as actual draws.
    # Scan within a conservative range, do not infer verified results from numbering.
    start=date(now.year,1,1)
    days=(now-start).days
    return min(160,max(1,int(days*3/7)+3))

def sync(game:str=Query('super')):

        today=date.today();estimate=expected_latest(game,today)
        existing={r[0] for r in db.execute('SELECT draw_number FROM results WHERE game=? AND year=?',(game,today.year))}
        candidates=[n for n in range(max(1,estimate-5),estimate+3) if n not in existing][:8]
        accepted=0;errors=[]
        for n in candidates:
            try:
                res=fetch_one(game,today.year,n)
                db.execute('INSERT OR IGNORE INTO results VALUES(?,?,?,?,?,?,?)',(game,today.year,n,res['date'],json.dumps(res['numbers']),res['sourceUrl'],res['fetchedAt']))
                accepted+=1
            except requests.RequestException as e:
                errors.append('Resmî siteye ağ erişimi başarısız')
                break
            except ValueError as e:
                errors.append(f'Çekiliş {n}: {str(e)}')
                if '403' in str(e) or '429' in str(e):break
        status='ok' if accepted else ('limited' if errors else 'no_new')
        message=(f'{accepted} yeni resmî kayıt doğrulandı.' if accepted else 'Yeni doğrulanmış sonuç alınamadı.')
        if errors:message+=' '+errors[0]
        checked=time.time()
        db.execute('INSERT INTO checks VALUES(?,?,?,?) ON CONFLICT(game) DO UPDATE SET checked_at=excluded.checked_at,status=excluded.status,message=excluded.message',(game,checked,status,message))
        return {'status':status,'message':message,'checkedAt':datetime.fromtimestamp(checked,timezone.utc).isoformat(),'results':rows(db,game,500),'cached':False}

                       (game,year,datetime.now(timezone.utc).isoformat(),'running',start)).lastrowid

                           (game,year,n,reason,datetime.now(timezone.utc).isoformat()))
